emacs-将光标所在org-link内容插入为quote代码块

[2026-10-25 日 00:15]

有的时候，你不想在链接中跳来跳去，只想就地查看链接指向的内容。

之前我是用 org-transclusion + org-transclusion-blocks 实现的，但后者的作者失踪近1年了（考虑到他是俄语区人士，也许已经消失在乌克兰前线）。

所以结合自己平时使用的限制，干脆让 DeepSeek 生成了一个转换 org-store-link 可存储对象为 quote-block 的包，无其他依赖，保持极简，当然功能也是极简的。

具体使用方法请查看 repo 的 README ： https://github.com/TomoeMami/org-quote-link
